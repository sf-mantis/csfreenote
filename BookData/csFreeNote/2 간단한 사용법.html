▶ csFreeNote 간단한 사용법

Ctrl+Shift+Insert 키를 누르면 새 폴더가 생성됩니다. 적당한 이름으로 변경하세요.

Ctrl+Insert 키를 누르면 새로운 노트를 작성할 수 있습니다.

그 밖의 단축키는 하단의 ▶ 단축키 모음을 참고해 주세요.

...

csFreeNote는 노트를 3가지 모습으로 보여줍니다.

  • 보기 모드 — 문서 안을 탐색하거나 조회합니다.
  • 편집 모드 — 에디터 화면에서 내용을 편집합니다.
  • 소스 모드 — 파일의 HTML 문서를 직접 편집합니다.

보기 모드는 노트를 원래 모습 그대로 보여줍니다. 고칠 수 없으니 실수로 내용이 변경되는 일을 방지할 수 있습니다.

편집 모드는 보이는 그 자리에서 바로 고칩니다. 화면에 보이는 것이 파일에 들어가는 것과 같습니다. 입력을 멈추면 잠시 뒤 저장됩니다.

소스 모드는 파일에 실제로 들어 있는 HTML을 그대로 보여줍니다. 직접 손대고 싶을 때 쓰세요.

▶ 단축키 모음

Ctrl+Insert 새 노트
Ctrl+Shift+Insert 새 폴더
F2 이름 변경
Delete 삭제 (휴지통으로)
Ctrl+S 지금 저장
Ctrl+F 이 노트에서 찾기
Ctrl+V 붙여넣기 (글꼴·크기는 노트를 따름)
Ctrl+Shift+V 글자만 붙여넣기
F5 날짜와 시각 넣기 (편집 모드)
Ctrl+Shift+D 노트 검색
Ctrl+D 탐색기에서 열기
Ctrl+1 … Ctrl+9 저장해 둔 글자 서식
Esc 왼쪽 트리 감추기
F12 개발자 도구

트리에서 노트나 폴더를 끌어다 다른 폴더에 놓으면 옮겨집니다. Ctrl 키를 누른 채 놓으면 복사됩니다. 잘못 옮겼다면 화면 아래 알림의 되돌리기를 누르세요.

오른쪽 버튼을 누르면 열기 · 이름 변경 · 복제 · 삭제 메뉴가 나옵니다.

▶ 폴더 설명

폴더를 선택하면 그 폴더의 설명 문서가 열립니다. 무엇을 모아 둔 곳인지 폴더에 적어 두면 나중에 찾기 쉽습니다.
