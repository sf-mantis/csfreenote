# csFreeNote

내 PC 안에 두고 쓰는 HTML 노트 프로그램.

노트 하나가 HTML 파일 하나이고, 폴더 구조가 곧 분류다. 데이터베이스도 독자 포맷도
없어서 **폴더째 복사하면 그대로 옮겨진다.** 프로그램을 지워도 노트는 파일 탐색기에서
열리고 브라우저에서 읽힌다.

Windows용 Electron 앱이다.

## 설치

[Releases](../../releases) 에서 `csFreeNote-<버전>-setup.exe` 를 받아 실행한다.

- 관리자 권한이 필요 없다. `%LOCALAPPDATA%\Programs\csFreeNote` 에 설치된다
- 제거할 때 **노트를 함께 지울지 물어본다.** 아니요를 고르면 노트·양식·설정이 남는다
- 서명하지 않은 실행 파일이라 처음 실행할 때 SmartScreen 경고가 뜬다.
  *추가 정보 → 실행* 으로 진행한다

## 무엇을 하는가

**노트를 원래 모양 그대로 다룬다.** 표 레이아웃, `<font>` 태그, 인라인 스타일, 문서
자체의 스타일시트 — 어떤 HTML이든 편집을 거쳐도 살아남는다. 편집기가 문서를 자기
방식으로 다시 만들지 않고, 저장할 때 `<body>` 안쪽만 갈아끼우기 때문이다.

- **세 가지 보기** — 보기 / 편집 / 소스. 소스 탭에서 HTML을 직접 고칠 수 있다
- **본문 검색** — 파일 이름이 아니라 내용을 찾는다
- **밤·낮 테마** — 노트 내용의 색도 함께 옮긴다. 반전이 아니라 색상은 지키고 밝기만
  바꾸므로, 파란 표 위의 흰 글씨 같은 관계가 무너지지 않는다
- **텍스트 서식 9개** — Ctrl-1 … Ctrl-9 에 글꼴·크기·색·굵기·정렬을 저장해 둔다
- **노트책 여러 개** — 서로 다른 폴더를 따로 관리한다
- **이미지 붙여넣기** — 노트 옆 `_images/` 에 저장하고 상대 경로로 건다
- **붙임 파일** — 노트마다 파일을 딸려 둔다. 편집 모드 아래 칸에서 붙이고, 고른
  파일을 본문에 넣는다 (그림은 그림으로, 그 밖은 링크로). 노트를 옮기거나 이름을
  바꿔도 따라간다
- **트리 끌어놓기** — 노트와 폴더를 옮기고, Ctrl을 누르면 복사한다
- **PDF로 저장** — 노트만 담는다. 트리도 도구모음도 들어가지 않고, 밤 모드로 보고
  있어도 원래 색으로 나온다. 종이로는 그 PDF를 열어서 뽑는다
- **새 판 알림** — 시작할 때 한 번만 확인하고, 새 판이 있을 때만 알린다. 받는 것과
  설치하는 것은 직접 한다. 설정에서 끌 수 있다

### 노트가 상하지 않게 하는 것들

- **더티일 때만 쓴다.** 열기만 한 파일은 디스크에 닿지 않는다
- **구조가 통째로 사라지는 저장은 거부한다.** 표·글꼴·style 속성이 한꺼번에
  없어지면 저장을 멈추고 알린다. 상태 줄은 `저장 보류` 로 남고, 정말 그럴 뜻이었다면
  거기를 눌러 그래도 쓸 수 있다. 저장하지 못한 채 노트를 떠나거나 앱을 닫으려 하면
  먼저 물어본다
- **원자적 쓰기** — 임시 파일에 쓴 뒤 바꿔치기한다. 전원이 나가도 반쯤 쓰인 노트는
  없다
- **`_backup/` 에 직전 판 한 세대.** 노트를 옮기거나 이름을 바꾸면 백업도 따라간다
- **외부 변경 감지** — 다른 프로그램이 노트를 고쳤으면 덮어쓰기 전에 알린다

## 단축키

| 키 | 하는 일 |
|---|---|
| `Ctrl` `Insert` | 새 노트 |
| `Ctrl` `Shift` `Insert` | 새 폴더 |
| `F2` | 이름 바꾸기 |
| `Delete` | 삭제 (휴지통으로) |
| `Ctrl` `S` | 저장 |
| `Ctrl` `P` | 이 노트를 PDF로 저장 |
| `Ctrl` `F` | 이 노트에서 찾기 |
| `Ctrl` `H` | 이 노트에서 찾아 바꾸기 |
| `Ctrl` `Shift` `D` | 본문 검색 (노트책 전체) |
| `Ctrl` `Shift` `V` | 서식 없이 붙여넣기 |
| `Ctrl` `D` | 탐색기에서 이 노트 보기 |
| `F5` | 편집 중 날짜·시각 넣기 |
| `Ctrl` `1` … `9` | 텍스트 서식 적용 |

## 노트는 어디에 있나

설치본은 **실행 파일 옆**에 둔다.

```
%LOCALAPPDATA%\Programs\csFreeNote\
  csFreeNote.exe
  BookData\          노트
  csTemplate\        새 노트 양식
  csFreeNote.json    설정
```

실행 파일 옆에 쓸 수 없는 자리에 설치되었을 때만 `%APPDATA%\csFreeNote` 로 물러선다.

폴더 안의 `_backup/` 과 `_images/` 는 트리와 검색에서 감춘다.

## 직접 빌드하기

Node.js 20 이상이 필요하다.

```
npm install
npm start          앱 실행
npm run dev        Vite 개발 서버와 함께 실행
npm run build      렌더러 빌드
npm test           검증 스위트
npm run dist       설치본 빌드 (release/)
```

렌더러(`src/`)를 고쳤으면 `npm run build` 를 해야 `npm start` 에 반영된다.

코드를 만지기 전에 [DEVELOPMENT.md](DEVELOPMENT.md) 를 읽어 두면 좋다. 저장이 왜
지금처럼 되어 있는지가 거기 있다.
